# Сайт-профиль А. Г. Параскуна (Jekyll → GitHub Pages)

Статический сайт из двух страниц в едином стиле:
- **index.html** — профиль (шапка с фото, публикации, преподавание, деятельность и т. д.);
- **projects.html** — проекты (карусель + описание + ссылки на публикации).

Сайт двуязычный (RU / EN, переключатель справа вверху). Собирается **Jekyll**,
который GitHub Pages запускает автоматически: вы правите текст в `_data/`, делаете
`git push` — сайт пересобирается сам, локальная сборка не нужна.

---

## Как опубликовать на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите туда **всё содержимое этой папки**
   (можно через веб-интерфейс «Add file → Upload files» или через git).
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment**: Source = **Deploy from a branch**,
   Branch = **main**, папка = **/ (root)**. Сохраните.
4. Через 1–2 минуты сайт будет доступен по адресу из того же раздела Settings → Pages.

### ⚠️ Важно — один параметр в `_config.yml`

Откройте `_config.yml` и задайте `baseurl`:

- Если репозиторий называется **`ВАШ-ЛОГИН.github.io`** (адрес `https://ВАШ-ЛОГИН.github.io`)
  → оставьте `baseurl: ""`.
- Если репозиторий называется как угодно иначе, например **`paraskun`**
  (адрес `https://ВАШ-ЛОГИН.github.io/paraskun`)
  → напишите `baseurl: "/paraskun"` (с косой чертой в начале, точно как имя репозитория).

Без этого не подгрузятся стили, скрипты и фото. Это единственная настройка, которую нужно сделать один раз.

## Где что лежит

```
index.html          — страница профиля (шаблон)
projects.html       — страница проектов (шаблон)
_config.yml         — настройки (baseurl!)
_data/              — ВЕСЬ КОНТЕНТ (то, что вы редактируете)
images/             — фотографии
files/              — PDF публикаций (необязательно)
assets/css/style.css— оформление
assets/js/          — скрипты (переключатель языка, карусели)
_includes/head.html — общий <head>
Gemfile             — только для локального предпросмотра
```

Файлы в `_data/` — это списки в формате **YAML**. Двуязычные поля пишутся так:
`{ru: "текст", en: "text"}`. Отступы важны (два пробела).

## Добавить публикацию

Откройте нужный файл: `_data/articles.yml` (журналы), `_data/abstracts.yml`,
`_data/conferences.yml`, `_data/books.yml`, `_data/proceedings.yml`,
`_data/preprints.yml`, `_data/reviews.yml`.

Скопируйте существующую запись (начинается с `- `) и отредактируйте:

```yaml
- au: {ru: "Параскун А.Г., Пальчиков Е.И.", en: "Paraskun A.G., Palchikov E.I."}
  t:  {ru: "Название по-русски", en: "Title in English"}
  v:  {ru: "Журнал. 2027. Т. 1. С. 1–10.", en: "Journal. 2027. V. 1. P. 1–10."}
  doi: "10.xxxx/xxxxx"        # необязательно
  db:  [WOS, Scopus, РИНЦ]    # необязательно
```

### Аннотация с фото (кнопка «Аннотация»)

Добавьте к записи блок `abs` — под публикацией появится кнопка, раскрывающая
текст и карусель фото:

```yaml
  abs:
    text: {ru: "Текст аннотации.", en: "Abstract text."}
    photos: [рис1.jpg, рис2.jpg]   # файлы из папки images/ (можно и без фото)
```

## Добавить блок в «Деятельность»

Файл `_data/activity.yml` — блок = карусель фото + подпись:

```yaml
- title:   {ru: "Название мероприятия", en: "Event name"}
  caption: {ru: "Описание.", en: "Description."}
  photos:  [фото1.jpg, фото2.jpg, фото3.jpg]
```

Несколько фото → карусель со стрелками. Файлы кладите в `images/`.

## Добавить проект (страница «Проекты»)

Файл `_data/projects.yml`:

```yaml
- title: {ru: "Название проекта", en: "Project name"}
  desc:  {ru: "Описание.", en: "Description."}
  photos: [proj1.jpg, proj2.jpg]
  files:
    - {label: "Публикация 1", href: "https://doi.org/10.xxxx/xxxx"}
    - {label: "PDF статьи",   href: "files/moya-statya.pdf"}
```

`href` — ссылка (`https://…`) или путь к PDF в папке `files/`
(например `files/moya-statya.pdf`, без косой черты в начале — тогда работает при любом `baseurl`).

## Фото в разделе «Преподавание»

Файл `_data/teaching.yml`. Слева список курсов (`items`), справа карусель из `photos`:

```yaml
photos: [лекция1.jpg, лекция2.jpg]
items:
  - c: {ru: "Физика", en: "Physics"}
    term: {ru: "2025, 1 семестр", en: "2025, semester 1"}
    type: sem      # sem = семинары, prac = практикум
    h: 72
```

---

## Заменить фото в шапке

Положите файл в `images/` и укажите его имя в `_data/profile.yml`, поле `photo:`.

## Посмотреть локально (по желанию)

Публиковать проще прямо на GitHub. Но если хотите видеть изменения до пуша:

```
gem install bundler jekyll
bundle install
bundle exec jekyll serve
```

Откроется `http://localhost:4000`. Для быстрого просмотра без Jekyll есть
отдельный архив `local-preview` — там те же страницы с относительными путями,
файл `index.html` открывается двойным кликом (но правки из `_data/` в нём не
подхватываются автоматически — он только для просмотра готового вида).
